# Baseline landscape for layer-level fault attribution (2026-11-02, v1 after verification)

## 0. What a baseline must consume here
Per run: ~80 per-layer deviation features (some vs a clean reference, some run-only), known 4-5 node layer DAG (mesh and places siblings; objects from labeled mesh; rooms from places), query outcomes, injected layer, benign near-harmless runs, seeds. One feature vector per run, no per-layer time series.
Consequences: (1) DAG known, so causal discovery (PC/FCI/Granger/NOTEARS) is unnecessary; (2) n small, so CI-test methods are under-powered; (3) "normal period" = benign-perturbation runs, not clean repeats (Hydra deterministic); (4) any method that re-runs a module needs the simulator/oracle and is not reference-free.

Metrics (CIRCA [V-full], DejaVu [V-full]): AC@k = recall of true root causes in top-k, monotone in k; Avg@k = mean of AC@1..AC@k; k=5 reported because a survey says 73 % of developers read only top-5 (CIRCA). DejaVu: A@k and MAR (mean average rank). RCD: top-k recall. With 4-5 layers k<=3 is the meaningful range.
Benchmarks: Pham, Ha, Zhang ASE 2024 (arXiv 2408.13729) [V-full]: 9 causal discovery + 21 RCA methods; CausalRCA, RCD, CIRCA, NSigma, BARO best; PC/FCI/Granger/LiNGAM/fGES/NTLR + PageRank/random walk mostly like Dummy; CIRCA and NSigma sensitive to the failure-time specification; synthetic results do not transfer to real systems. RCAEval: Pham, Zhang, Ha, Salim, Zhang; arXiv 2412.17015; 735 cases, 3 systems, 15 baselines [V-abs]; WWW 2025 companion [M].
Lesson for us: simple per-node deviation scores (NSigma, BARO) are strong in this literature, which matches our dev finding that naive is about as good as dependency-aware on single global faults. The rule "blame the most upstream abnormal node" is the DFS-over-abnormal-subgraph family and CIRCA's DA prior; it is not new.

## 2. Family B: consistency-based / model-based diagnosis
- Reiter 1987, A theory of diagnosis from first principles, Artificial Intelligence 32(1):57-95, DOI 10.1016/0004-3702(87)90062-2 [V-full]. Def. 2.4: a diagnosis is a minimal set D of components such that SD + OBS + {AB(c): c in D} + {not AB(c): c not in D} is consistent; diagnoses = minimal hitting sets of the conflict sets (HS-tree).
- Greiner, Smith, Wilkerson 1989, A correction to the algorithm in Reiter's theory of diagnosis, AI 41 [V-full]: HS-tree loses minimal hitting sets with non-minimal conflicts.
- de Kleer, Williams 1987, Diagnosing multiple faults (GDE), AI 32(1):97-130, DOI 10.1016/0004-3702(87)90063-4 [S; full text not retrievable]. ATMS conflicts + probabilistic ranking of multi-fault candidates.
- Steinbauer, Wotawa: Detecting and locating faults in the control software of autonomous mobile robots, IJCAI 2005 (short, pp. 1742-1743) and DX-05 workshop pp. 13-18 [S]: observers detect, a component model plus model-based diagnosis localizes.
- Antonante, Nilsen, Carlone, Monitoring of perception systems: deterministic, probabilistic, and learning-based fault detection and identification, Artificial Intelligence journal (arXiv 2205.10906, preprint stamped "submitted to Artificial Intelligence Journal" May 2022; final volume/pages not checked) [V-full]; earlier Antonante, Spivak, Carlone IROS 2021 arXiv 2005.11816 / 2011.07010 [V-title]. Code: MIT-SPARK/PerceptionMonitoring (same lab as Hydra). Tests are functions of a failure-mode subset ("scope"), outcome PASS/FAIL, PASS may be unreliable ("Weaker-OR"); syndrome = vector of outcomes; deterministic identification (D-FI) = smallest set of active failure modes consistent with the syndrome plus a-priori module-output relations (an output failing implies its module has an active failure mode), solved by integer programming; probabilistic = factor graph MAP; learning-based = GNN; t-diagnosability from redundancy. Their baselines: blame every mode in the scope of every failing test, or blame by sensor reliability (high recall, low precision). Evaluation: Apollo + LGSVL simulator; accuracy/precision/recall on module and output faults.
Needs: hand-declared check scopes and thresholds; no fault labels; no clean reference graph if checks are reference-free. Applicable: yes, directly. This is the closest classical competitor to CHECK + LOCALIZE; a reviewer from SPARK will know it.
Simplified (half a day): enumerate all 2^4 or 2^5 layer subsets, keep those consistent with the syndrome under (a) failing check => at least one layer in its scope active, (b) active layer in a layer's input set explains that layer's failing downstream checks only if the check scope contains the upstream layer; return min-cardinality sets, ties as sets; exoneration by PASS only for non-weak tests.

## 3. Family C: spectrum-based and statistical fault localization, delta debugging
- Barinel: Abreu, Zoeteweij, van Gemund, Spectrum-based multiple fault localization, ASE 2009, pp. 88-99 [S]: joins spectra with Bayesian MBD-style multi-fault candidates and posteriors.
- Delta debugging: Zeller, Hildebrandt, Simplifying and isolating failure-inducing input, IEEE TSE 28(2):183-200, 2002 [S]; Zeller, Isolating cause-effect chains from computer programs, FSE 2002, DOI 10.1145/587051.587053 [S] (compares program states of passing and failing runs to find where they first diverge = our "most upstream deviating layer vs a clean reference").
- Tarantula (Jones, Harrold, Stasko, ICSE 2002), Ochiai (Abreu, Zoeteweij, van Gemund 2007), statistical bug isolation (Liblit et al., PLDI 2005), survey (Wong, Gao, Li, Abreu, Wotawa, IEEE TSE 2016) [M].
- Pearson et al., Evaluating and improving fault localization, ICSE 2017 [V-full on the abstract]: rankings on artificial faults (mutants) differ from rankings on real faults; do not generalize FL conclusions from injected faults alone.
Needs: a coverage matrix (which tests exercise which elements) and pass/fail per test; delta debugging also needs re-execution and a passing reference. Ref-free: SBFL yes; delta debugging no.
Applicable: SBFL over (query x layer) with the TRACE lineage as coverage (Ochiai suspiciousness per layer). Weak when queries rarely fail (dev data: masked faults, 2-6 % failure for frame drop). Delta debugging only for config faults (minimal parameter delta), needs re-runs.

## 4. Family D: counterfactual / Shapley attribution
- Budhathoki, Minorics, Blobaum, Janzing, Causal structure-based root cause analysis of outliers, ICML 2022, PMLR 162:2357-2369 [S for venue; V-full on arXiv v1 1912.02724 by Janzing et al.]: known DAG, conditional outlier score (is the value unexpected given its parents), Shapley attribution of the target's outlier score to ancestors; implemented in DoWhy gcm.
- Budhathoki, Janzing, Blobaum, Ng, Why did the distribution change?, AISTATS 2021 (venue [M]), arXiv 2102.13384 [V-full on abstract]: Shapley attribution of a distribution change to causal mechanisms given the DAG.
- ShapleyIQ: Li, Tan, Wu, He, Li, ASPLOS 2023 [S: only a reference entry seen].
- Zhang et al., Which agent causes task failures and when? Automated failure attribution of LLM multi-agent systems, arXiv 2505.00212 (ICML 2025 per memory [M]) [V-full on abstract]: Who&When benchmark; All-at-Once, Step-by-Step, Binary Search; best 53.5 % agent-level, 14.2 % step-level. AgenTracer, Zhang et al., arXiv 2509.03312 [V-title].
- IRCA (Wang et al., NDSS 2025) [N]: intervention = replace a module's output by an oracle output and re-run; needs ground truth; single-fault OR semantics. CaRE (Hossen et al., RA-L 2023, arXiv 2301.07690) [N]: needs ~400 configuration runs; ranks configuration options. Han et al. 2025 (arXiv 2509.18460) [N]: needs per-hypothesis offline fault experiments; single fault.
Needs: DAG + benign data (Budhathoki); an oracle or a re-run (IRCA). Ref-free: no (needs normal distribution). Simplified: Budhathoki's conditional outlier score on one scalar per layer (regression on parent layers fit on benign runs, leave-one-out residual) plus Shapley over 2^4 coalitions; or reuse CIRCA RHT, which is nearly the same estimator.

## 5. Family E: supervised fault-location classification and unseen-fault protocol
- DejaVu [V-full]: supervised, random split 40/20/40 train/val/test, ground truth from the location and type of injected failures; RQ4 compares previously seen vs unseen failures; supervised baselines (iSQUAD, JSS'20) degrade on unseen units, random-walk heuristics do not.
- Gulrajani, Lopez-Paz, In search of lost domain generalization, arXiv 2007.01434 (ICLR 2021 [M]) [V-full]: leave-one-domain-out evaluation, training-domain vs test-domain (oracle) model selection; Recommendation 2: disclaim oracle selection.
Protocol for us: domain = fault FAMILY (label, depth, pose, frame-drop, config), not fault variant, because variants of one family share a signature. Train on all families but one, test on the held-out one; also group by seed and by scene segment so no run or seed appears on both sides; tune inside the training folds only. Eadro and DejaVu use random splits, so their numbers say little about unseen types.
Simplified: gradient-boosted trees or logistic regression on the ~80 features (and a second model on per-layer scores only), predict injected layer.

## 6. Recommended baselines (at most four)
1. Benign-normalized largest deviation (BARO/NSigma style): per-layer robust z (median/IQR from benign runs) of reference-free features and, separately, of with-reference features; blame argmax. Not a straw man here (Pham 2024). Straw man only if features are unnormalized.
2. CIRCA-style RHT + DA on the known layer DAG: regress each layer's deviation score on its parents using benign runs, z of the residual, add descendant maxima. The fair dependency-aware statistical comparator; needs only benign runs.
3. Antonante/Reiter-style minimum-cardinality diagnosis on the same check outcomes. Ablates our LOCALIZE rule against the textbook algorithm and handles multiple faults natively.
4. Supervised classifier under leave-one-fault-family-out (plus a random-node Dummy row and a query-failure-type-only row as floors, not counted as baselines).
Optional ablation, not a baseline: Ochiai SBFL over query lineage = TRACE alone.

## 7. Which comparison argues for cross-layer reasoning
Strongest: (a) two simultaneous faults in different layers, especially one upstream and one downstream (label noise + pose drift), where argmax (1) names one layer and "most upstream" explains the downstream one away while residual-given-parents (2) and set-valued MBD (3) can keep both; (b) localized faults (one room/area), where TRACE scoping should raise signal that global per-layer scores average out; (c) no-reference mode and unseen families, where supervised (4) loses its labels advantage. Each must show where (2)/(3) fail and ours holds, otherwise the dependency claim is empty.
Straw men: unnormalized argmax; always-same-layer; query-failure-only as the main comparator; PC-learned graph when the true DAG is known (Pham 2024: about Dummy); supervised with a random split (seed leakage); giving the baseline the clean reference but not ours (or the reverse): always report both information modes.
Honest read: on single global faults dependency-aware vs naive is a tie (our dev data and the AIOps benchmark agree), so the single-fault table cannot carry the novelty.

## 8. Protocol and metrics
Set-valued truth (geometry faults accept mesh or places); top-1 set-hit, AC@2, Avg@3, macro over fault families, abstain/masked reported separately; bootstrap CIs resampled by seed; thresholds and regressions fit on benign runs only; tune on seed 0, test on seeds 1 and 2; report seen-vs-unseen like DejaVu RQ4. Injected faults are artificial (Pearson 2017): add at least a few naturalistic faults.
